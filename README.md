# Smart Expense Tracker 
A simple Python-based application that helps users record, manage, and analyze their daily expenses.
About the Project
Smart Expense Tracker is a beginner-friendly Python project developed to practice programming fundamentals and intermediate Python concepts. It allows users to add expenses, view records, calculate total spending, analyze category-wise expenses, and delete records.
Features
- Add new expenses with category, amount, and description.
- View all recorded expenses.
- Calculate total spending.
- Display category-wise expense summaries.
- Delete expenses using their ID.
- Store expense records in a CSV file.
- Handle invalid inputs using exception handling.
- Automatically save expenses for future use.
Technologies Used
- Python 3
- CSV File Handling
- Built-in Python Libraries: `csv`, `os`, and `datetime`

 Python Concepts Practiced
- Variables and data types
- Conditional statements and loops
- Functions
- Lists and dictionaries
- File handling
- Exception handling
- Data processing and calculations
 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

```bash
python main.py
```
On Windows, you can also use:
```bash
py main.py
```
4. Select an option from the menu to start managing your expenses.
The application automatically creates an `expenses.csv` file when needed.
